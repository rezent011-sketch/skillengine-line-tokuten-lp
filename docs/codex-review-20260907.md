# Codex授業LP 修正記録（2026-09-07）

対象は `codex/`。既存のモバイル幅、20特典の名称、面談後のお渡し、予約URL、期限切れ後の相談受付を維持した。

## 修正内容

- 画面を開いたまま期限を迎えた場合も再生を停止し、特典を隠して相談予約へ切り替える。
- 壊れた保存値は失効として扱い、NaN表示や期限の再発行を防ぐ。保存が使えない場合も、そのページ内の期限と視聴状態は保持する。
- 公開ページの `#debug` バイパスを削除。
- 読み込み失敗・再生拒否・15秒の読み込み停滞を案内し、再試行できるようにした。エラー後も正常な視聴完了に復帰できる。
- 期限終了・読み込み失敗時のボタンは無料の個別相談予約に変更。通常は「プレゼントを受け取る」とし、面談予約と面談後の受け渡しであることを併記。
- 実装上の期限起算点は初回ページ表示。見出し・期限注記・FAQ・descriptionを一致させた。
- 再生ボタンをキーボード操作した場合のフォーカスを動画操作へ移す。視聴後の強制スクロールを廃止し、状態を読み上げで通知する。
- JavaScript無効・ページスクリプト取得失敗時も既存の相談予約へ進める。
- 動画を上へ移し、期限表示を簡潔にした。Noto Sans JP、余白、文字階層、特典のカテゴリ、固定ボタンの補足を整理。CSSはCodexページに限定。
- 動画・期限ロジックは `codex/lesson.js` に分離。動画URL変更もこのファイルで行う。

## 検証

Chromiumで11組の回帰チェックを実施。初訪問、95%視聴完了と再訪、開いたままの期限切れ、破損した保存値、HLSエラーと再試行、再生拒否とフォーカス、保存拒否、別タブの期限変更、JavaScript停止時、画面幅、既存ページ比較がすべて成功。

320 / 375 / 430 / 1440pxで横溢れなし。既存4ページ（トップ・Claude Code・セミナー・大感謝祭）は、時計と画像読込条件を揃えたスクリーンショット比較でピクセル一致。

実際のhls.js 1.5.20と既存HLS動画で、Chromiumでの再生開始・720pフレーム表示・標準コントロール・例外なしを確認。iPhone/LINE内ブラウザの実機確認は未実施。

## 未確定・公開時の注意

- 動画は40大特典と言っており、LPの正式な既存一覧は20大特典。数や特典名を新しく作らず、オーナーの判断を待っている。
- この変更の動画URLは、配信済みの `codex-lesson-v2`。未公開の動画URLへ先に切り替えない。
- 次の動画を公開する場合は、別slugへアップロード・再生確認後にURLを変更する。
- LINEのステップ・流入経路・配信開始はこの変更の対象に含まない。
