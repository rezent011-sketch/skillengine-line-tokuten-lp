# スキルエンジン LINE追加特典LP

スキルエンジン（ガガロットのAIスクール）向けの公式LINE追加特典ページです。個別面談のCTAはスキルエンジンのLIFF予約です。

## 公開URL（これを使う）

**https://rezent011-sketch.github.io/skillengine-line-tokuten-lp/**

- GitHub Pages。`main` に push すると `.github/workflows/pages.yml` が自動で公開します（1〜2分）。
- 4本目ウェビナー（Claude Code）のCTAは、このURLに向けてあります。

## 使わないURL

- `raw.githack.com/.../main/index.html` — 初回訪問者に「One more step / Open the page」の確認画面が挟まる。さらに `main` のキャッシュが残り、push直後に古い版を返すことがある。
- `rawcdn.githack.com/.../<コミット>/index.html` — 確認画面は同じ。コミット固定なので更新も反映されない。

## 構成

- `index.html` … 本体
- `style.v2.css` … スタイル（`style.css` から改名。githackの古いキャッシュを避けるため）
- `assets/` … 画像。`badge-*.png` は余白をそろえた透過PNG（元のjpgは縦ズレしていたため作り直し）
- `privacy.html` … プライバシーポリシー
